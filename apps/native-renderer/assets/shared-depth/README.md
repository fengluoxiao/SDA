# Approved HRTFHQ depth residual

The user accepted HRTFHQ plus half-strength retained61 residual on 2026-10-17, including front/rear motion, bottom-to-top and upper-left/top/upper-right 360RA motion. These banks contain only the fixed difference between the retained61 short-cue speaker filter and its zero-residual control. No KU100 direct response is mixed into HRTFHQ.

The retained61 recipe uses its default35ms cue window and0.5011872336272722 cue gain. The exported residual already includes the additional approved0.5 multiplier and common front-reference calibration1.0006917288377972. One stereo delay shift of0samples is used. Samples are planar little-endian float32 per speaker; JSON records each pair's offset and size. The 7.1.4 and360RA-13 banks are separate. Do not renormalize ears, speakers, songs or regenerated outputs.

At runtime the existing reflection-bus path supplies authored geometry, listener pose, source-motion attenuation and continuous tails. Beds and non-continuous source routes use the same prepared speaker response. Pure HRTFHQ direct responses remain byte-identical. Stereo and unsupported layouts receive no invented speaker mapping; explicit user room processing excludes this layer. No input prescan, analysis cache, second music decode, or Apple runtime API is required.
