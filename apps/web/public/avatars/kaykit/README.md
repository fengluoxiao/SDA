The GLB is unchanged and contains its texture, skin, skeleton, and animations.
SDA hides weapon accessory meshes at runtime and uses Idle, Walking_A,
Running_A, and Jump_Idle (airborne pose, not a dedicated flight animation).
The character is scaled to the existing camera/floor coordinates. Assets are
bundled by Vite and work offline; no model service or user download is needed.
