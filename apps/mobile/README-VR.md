# 纸盒 VR 空间视图

在 iOS / Android 的「设置 → 空间视图」中开启「纸盒 VR」，再进入空间标签页并点「全屏」。开关默认关闭。普通空间页面维持单视图；只有全屏且横屏时进入双眼视图。

## 使用

1. 首次进入时允许手机运动权限。手机会请求横屏；系统不允许自动旋转时，按提示手动横屏。
2. 面朝想作为正前方的方向，点「视角回中」。手机姿态驱动画面，支持横屏两个方向。
3. 点「镜片校准」，按实际设备调整眼距、镜片间距、屏幕横向可视宽度、垂直视场角、k1 和 k2。屏幕宽度是实际 GL 画面在手机屏幕上的横向物理宽度，不是屏幕对角线尺寸。
4. 点「查看完整网格」可收起参数面板，通过眼镜检查网格；轻点画面恢复按钮，再点「调整校准参数」。校准完成后点「完成校准」。默认参数仅作为手动调整的起点，不对应某款眼镜的认证配置。
5. 点「开始观看」隐藏按钮。观看中轻点画面可再次显示按钮，点「退出 VR」返回原空间页面；Android 返回键也可退出。

开关和校准值保存在已有的界面偏好文件中。不会生成音频或整曲渲染缓存。声道音箱仍由独立的「显示声道音箱」开关控制，默认隐藏。

## 当前范围

- 共用一套场景、一个 GL 上下文，两只眼有真实相机间距，并非复制同一幅画面。
- 两眼分别绘制到复用的 GPU 纹理，经径向镜片畸变校正后，一次提交完整屏幕画面。
- 提供手动镜片参数和校准网格，暂未实现 Cardboard 二维码设备参数导入。
- 手机姿态在本功能中控制视觉相机；空间音频继续使用原有播放与耳机头追设置，不会自动把手机运动覆盖到音频监听者。
- 只有处于前台、空间全屏可见时才连接姿态与防休眠。回到系统桌面时暂停这些工作，保留全屏、横屏锁定和视角回中基准；重新进入应用后仍在 VR 全屏。主动退出才恢复进入前的旋转限制并释放双眼纹理。
- 仍遵循空间页的 60 / 120fps 设备策略。双目实际帧率和具体眼镜的融合效果需要在原生设备上验证，不能以浏览器或单目结果代替。

## 预览和安装包

Expo SDK 58 的预览与安装包使用相同的界面、相机和畸变代码。安装包需包含 `expo-sensors`，旧安装包没有对应原生模块时会提示更新。运动权限描述通过 Expo 配置插件和 `NSMotionUsageDescription` 写入原生工程。

自动检查覆盖校准值恢复、无效参数、左右眼视差、原生姿态约定、回中、旋转恢复竞态、权限拒绝、延迟授权后退出、后台清理与纹理释放。浏览器画面检查使用独立于生产代码的模拟姿态输入；这不等于真实手机或纸盒眼镜验收。
