# 声学研究辅助缺陷审计

日期：2026-11-27。范围是检查现有共享原生渲染器的实际缺陷。

## 保留现有听感与默认值

保留原来的近场增益模型、0.2 m 下限、700 Hz 低频棚形及默认源遮挡策略。模型简化、艺术性处理和缺少人体实测数据，都不能单独证明代码有错。本次没有替换 HRTF、引入数据库、增加扫描或新增声音预设。

研究参考：

- Brungart & Rabinowitz，近距离声源 HRTF：[10.1121/1.427180](https://doi.org/10.1121/1.427180)。用于检查物理距离、方向坐标与双耳线索是否混淆。
- Duda & Martens，球形头部模型的距离依赖：[10.1121/1.423886](https://doi.org/10.1121/1.423886)。用于理解现有模型的适用范围，不把另一模型的存在作为必须更换算法的理由。
- 华南理工近场 HRTF 测量研究：[10.1121/1.5027019](https://doi.org/10.1121/1.5027019)。作为近场方向和距离测量方法的参考。

## 已确认并修复

1. **真实米数被手动坐标比例覆盖。** 开启手动映射时，原分支优先采用归一化位置，忽略已经存在的有效 `distance_m`。快、常规混音器现均优先使用真实米数。
2. **反射声距离单位不一致。** 原代码在某些分支使用坐标半径，在另一些分支使用 `distance_m/metres_per_unit`。同一 0.3 m 声源会因手动比例不同，得到 1.0 或 0.30625 等不同的反射发送比例。现在统一以米计算，保留既有发送曲线，0.3 m 对应 0.475。
3. **明确的无限远标记丢失。** 协议收到 `distanceInfinite=true` 后只留下 `distance_m=None`，与未提供距离无法区分。开启手动映射后，无限远声源会被错误当成近场。现在将无限远标记保留到定时元数据和声源状态，旁路近场增益、近场反射衰减及有限距离强度修正。
4. **只更新距离的元数据重置运动轨迹。** 原代码将接收时的位置存入定时事件；事件稍后执行时，以旧位置替换正在进行的移动。现在距离事件只更新距离字段，保留当前轨迹、形状和方向属性。覆盖即时/定时、有限/无限远更新。
5. **文件的显式遮挡开关被后续默认设置覆盖。** 文件禁用预处理时，初始化顺序会把其明确关闭的遮挡开关恢复为默认开启。现在在预处理配置完成后恢复文件显式参数，普通播放默认值保持原样。
6. **低频修正残留固定高频增益。** 原指数低通在 Nyquist 处没有零点，低频棚形修正会残留到高频。改用相同约 700 Hz 的双线性一阶低通，保留目标低频增益与 20 ms 平滑。测试参数 `[1.3,0.6]` 下，8 kHz 变化由约 `+0.136/-0.178 dB` 降到 `+0.019/-0.017 dB`；这是滤波器响应测量，不代表已验证人耳主观改善。

没有改变既有空间平衡控制器的增益政策；其预算仍根据实际输出测量，峰值保护的衰减不能充当额外余量。

## 验证

先复现再修复的两项新增回归：

- `explicit_infinite_distance_cannot_become_near_when_manual_mapping_is_enabled`：修复前检测到非单位近场增益，修复后通过。
- `queued_distance_only_update_preserves_the_existing_object_trajectory`：修复前预期移动终点 `[1,0,0]`，实际退回 `[0,1,0]`；修复后通过。

定向原生回归命令：

```sh
cargo test --manifest-path apps/native-renderer/Cargo.toml --no-default-features --locked --lib -- near_field distance occlusion queued_object_metadata --nocapture --test-threads=1
```

30 项通过。覆盖旧近场音色约束、8 组两布局/两混音器的距离与手动比例对照、360RA 底部声道/LFE、无限远元数据、距离更新不中断轨迹、原遮挡状态和文件参数覆盖，以及近场与音量平衡/输出余量/峰值否决/seek 重置的组合。

另以 `--features caller-participating-dsp` 执行两项联合场景和两项新增缺陷回归，4 项通过。原始近场增益函数与调整前源码进行去空白对比，语义内容一致。

本轮验证范围为原生代码及合成 PCM，没有把模型比较或自动测试当作实体耳机听测。
