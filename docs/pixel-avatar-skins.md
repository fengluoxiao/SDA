# 像素角色皮肤

沉浸模式 → 皮肤 → 导入皮肤，选择 Minecraft 标准 PNG 皮肤。

- 支持现代 64×64 和旧版 64×32；不支持皮肤预览截图、资源包或 Marketplace persona 文件。
- 经典 4 像素与纤细 3 像素手臂可手动切换；旧版皮肤自动使用经典手臂。
- 支持头部帽子、衣服、袖子与裤子的第二层透明贴图。
- 旧版左右肢体按皮肤规则镜像补齐；处理旧版不透明帽子背景和基础层透明度。
- 最近导入的皮肤与手臂类型保存在本机；可恢复内置原创默认皮肤。不上传皮肤，不需要联网。
- 此功能只替换可视角色，不更改音频监听位置或 HRTF。

验证：静音浏览器验证皮肤转换、非法文件拒绝、持久化、恢复默认与动画；生产构建包含默认 PNG。
