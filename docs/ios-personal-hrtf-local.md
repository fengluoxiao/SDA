# iPhone 本机个人 HRTF：实验实现状态

本实验的目标是在同一台 iPhone 上完成前置 TrueDepth 深度采集、刚性配准、三维表面重建、质量检查、Mesh2HRTF 声学求解、HRIR 生成和 SDA Spatial 档案安装。用户运行时不需要电脑、服务器、Python 或 Blender。Face ID 的身份认证接口不提供个人 HRTF；这里使用的是前置 TrueDepth 测得的深度与相机标定。

**当前不是完整可用的个人适配功能。** `PersonalHrtfCoordinator` 需要注入实现完整流程的 `PersonalHrtfLocalPipeline` 才能开始采集，默认构建尚未注入该实现。不会把扫描完成、编译通过或合成球面测试通过当作个人 HRTF 生成完成。

## 已有代码

- `PersonalHeadScan.swift` 只启用前置 TrueDepth。同步的深度、颜色和标定直接送入本机重建器，不保存整段原始相机帧，不再导出扫描供电脑处理。
- `PersonalHrtfFusion/PersonalHrtfReconstruction.swift` 使用固定版本 StandardCyborgFusion 在 iOS 本机执行配准、surfel 融合和 Poisson 候选表面重建。不用 ARFaceGeometry 代替耳廓。
- 重建器关闭原始帧保留，限制输入规模，前后台切换、取消及内存告警会中止任务；临时测量表面在写入后释放一份重复的融合模型。上游分辨率 6 对应实际八叉树深度 9。Poisson 的精确峰值内存仍需实机测量，当前不宣称有完整的硬内存限制。
- `PersonalHrtfMeshCheck.swift` 与 `SdaHrtfMesh.cpp` 检查有限坐标、缓冲区布局、面索引、退化三角形、闭合流形、面朝向、连通性、自相交和实测深度支持。检查面内部采样点，避免只检查顶点而放过大块补洞。检查可取消，并限制输入和计算工作量。
- 网格支持距离上限 1.5 mm、面边长上限 12 mm 是**候选几何筛查参数**，不是经验证的个人 HRTF 精度指标。声学频率对应的网格分辨率和耳廓保真必须另外验证。此筛查不推断耳入口，不自动修补耳廓，也不安装档案。
- Mesh2HRTF NumCalc 被移植为应用内 C++ 库。各任务使用独立状态和工作目录，有数值数组预算、取消和错误返回；预算根据 iOS 报告的进程可用内存计算，保留应用／音频余量，最多 768 MiB 且不超过物理内存的八分之一；大数组分配前与计算期间继续检查剩余内存，不能据此宣称已消除所有系统内存终止风险。不启动外部可执行程序，不改变进程工作目录。
- 零长度声源数组统一表示为空指针，避免 Apple 优化编译下的空数组资源登记问题。网格维度在上游整数乘法前限制为最多 20,000 个节点／单元，防止索引先溢出再绕过数组预算。更大的头部模型需要经过验证的本机网格准备，不能直接送入求解器。
- `sda_hrtf_make_hrir` 在本机完成参考声压修正与逆 FFT，保留左右耳独立幅度、相位和延迟，不做各耳峰值归一化。
- 原生响应校验复用实际播放加载器，执行校验时不创建音频输出。

## 构建与数值验证

Apple 工作流使用 Xcode 27.1 / iOS SDK 27.1，编译目标最低 iOS 16.4。GitHub 的 Apple 构建机器只用于构建和测试，不参与用户的采集、重建或计算。

已验证的基础求解器版本见 [iOS 原生核心运行 44477780950](https://github.com/fengluoxiao/SDA/actions/runs/44477780950)：

- Apple 主机优化构建运行；ASan / UBSan 主机构建运行；实际 iPhone arm64 静态库编译；Swift 类型检查；iOS 模拟器进程内运行。
- 与未改动的上游 NumCalc 对比 100、1000、6000 Hz 的合成球面参考声压，与上游 Python 数值例程对比 HRIR。
- 重复左右耳任务、并发独立任务、内存超限、取消、失败后恢复、工作路径限制和数组释放检查。
- **这些是合成数值回归，不是真人扫描或听感验证。**

网格合成回归覆盖闭合表面、缺面、非流形边、断开的表面、反向面、折叠自相交、无测量支持的补洞、法线错误、规模限制及取消。后续工作流也编译和运行这些检查。

重建库构建脚本显式封装 Metal 着色器、Objective-C 模块、框架标识及版本信息。模拟器资源测试会区分“资源存在”“GPU 可用”“重建器初始化成功”和“真实前置相机扫描”；没有 GPU 的执行环境不会被记为完成了 Metal 初始化。

## 尚未完成，不能用默认值替代

1. 真实前置 TrueDepth 的完整头耳覆盖、尺度精度、耳廓细节和遮挡情况验证。
2. 在测量表面上可靠确认左右耳声学入口、声源面与头部坐标；不得用通用耳朵、脸部网格或外观检测结果冒充实测耳入口。
3. 在 iPhone 内存预算内准备完整声学网格，验证分辨率与频率收敛，再生成本机 NC 输入及评估方向。
4. 对真实完整头部模型验证内存、计算时间、温度和取消行为；小球面回归的耗时与内存不代表真实头部模型。上游示例头部（8,718 顶点／17,432 三角面）的资源预估在 100／1000／6000 Hz 分别为约 598／414／486 MB 的矩阵内存，尚未包含全部工作内存。这是资源估算，不是实机峰值或有效个人 HRTF 的生成测试。
5. 把求解声压、HRIR 构建、完整方向档案安装连接成可取消的本机流程。
6. 为个人实测响应接通 SDA Spatial 已有的参考音色与空间处理，验证前后、上下及 360RA 下方方向；保存的原始测量响应保持不变。
7. 安装到真实 iPhone 后进行端到端采集和听感测试。
