## 已查明的增益与不能推断的事

原增强中，两个高能前方 ±45 度路径（本素材 Obj11/13）额外层增益为 0 dB，仍跟随 master +2 dB；水平 ±90 度两路（本素材 Obj15/21）额外层增益为 +6 dB，叠加 master 后为 +8 dB。前/侧语音频带 PCM 的宽带相关性很低，不能由此声称这些对象是精确分离的主人声或复制人声。

源码的新规则不使用这些编号，也不使用歌曲、时间窗或声音强弱。此轮修正的是增强设计中的“主层自动抬升”，不是已经证明忠实解码存在某个故障。

## 通用修正

- 水平前方与侧方直到绝对方位角 105 度归入保护主层；105–135 度连续进入后方辅助层。
- 高低处仍使用原有高度权重，绝对高度 30 度达到完整辅助增强。
- 开启组合增强时，master 仍 +2 dB；主层用 -2 dB 配套补偿取消这项自动抬升，**峰值保护前净增益恢复 0 dB**，不把主层压到原始基准以下。
- 完整辅助层维持额外 +6 dB，叠加 master 为 +8 dB；中间按空间权重连续过渡。
- LFE 不进入辅助/主层配套增益，仍沿用 master 的全局设置。普通层增益 API 仍可独立使用，主层补偿只属于组合增强预设。
- 仍保持元数据位置、原 PCM、metadata gain、61 点测量和既有空间线索；不新增人声检测或弱声源检测。

该规则也会保护其他歌曲的水平侧方内容，不只主人声；可能改变之前其他素材的增强听感，因此仍是待听候选，而不是已经验收的全曲修复。
