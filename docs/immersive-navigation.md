# 沉浸视角控制

进入空间声场的沉浸模式后，使用顶部工具条进入或退出全屏。

| 操作 | 功能 |
| --- | --- |
| F5 / 视角按钮 | 按第一人称 → 第二人称（角色正面）→ 第三人称（角色背后）循环切换；沉浸模式下不触发刷新 |
| F6 | 角色坐标归零并停止移动，保留朝向、当前视角与飞行模式 |
| 窗口模式按住画面拖动 | 转向；松手立即停止，不自动锁定鼠标 |
| 全屏模式点击画面、移动鼠标 | 锁定鼠标并转向；锁定不可用时可拖动转向 |
| 全屏按住 Alt / 松开 Alt | 显示鼠标并暂停转向以操作工具栏 / 重新锁定鼠标恢复转向，不退出全屏 |
| Esc | 释放鼠标；浏览器也可能同时退出全屏 |
| W / A / S / D | 按当前朝向向前、左、后、右移动 |
| Shift | 加速 |
| 单击空格 | 步行时起跳，可落在音箱表面；空中不能重复起跳 |
| 双击空格（300 ms 内） | 切换飞行与步行；工具条显示“飞行中” |
| 飞行时按住空格 / Ctrl | 上升 / 下降 |

移动采用按时间计算的速度和平滑加减速，斜向速度归一化。
鼠标输入按渲染帧合并，最大角速度为 8 rad/s；超出单帧上限的
位移直接丢弃，不排队继续转向，以抑制远程鼠标跳变和突发输入。
普通低速转向保持原有灵敏度。第三人称遇到边界时沿相机射线缩短
跟随距离，不再分别裁切坐标后重新瞄准，避免大幅转向时偏转。
镜头限制在可视房间边界内；第三人称跟随可见角色。恢复步行后
受重力影响落回地面或音箱表面；走出音箱边缘后自动下落。退出沉浸视角会还原进入前的相机位置、朝向与视场。
输入框、文本编辑区域不接收移动快捷键；松键、失焦、后台切换与
释放鼠标锁定会清空移动状态，避免持续漂移。

此功能控制可视相机，不改变音频听音位或头部追踪数据。
目前不是 WebXR 会话，不包含 VR 设备跟踪或真实房间碰撞模型。

验证：浏览器实际渲染检查覆盖 WASD 位移与停止、F5 无刷新切换、
双击空格与飞行升降/落地、文本输入隔离、全屏切换和失焦清理。

所有可见音箱（含顶部声道）均可落脚。保留小跳高度，高处音箱需飞到上方后切回步行；活动边界随音箱范围扩展，为角色站立和起跳留出空间。

地面保持小跳；从音箱起跳时使用较低重力延长滞空，跳高约 0.55，支持从低音炮跳到耳平音箱。音箱间较远时按住 Shift 配合方向键和空格跳跃。
