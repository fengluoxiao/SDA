# 共享 master 增益控制与试听（2026-10-08）

## 用户方向与范围

用户纠正：不使用“弱声源增强”或本曲 Obj12–24 +6 dB 作为通用规则，应在完整 master 上处理整体电平。原 C 仅保留为历史听感参照。**本实现不会复现 C 的相对声源组提升，也不证明头顶人声的相对清晰度问题已经解决。**

新增共享原生总输出 preamp：默认 **0 dB**、允许 -12 至 +12 dB。它位于完整混音、耳机补偿、EQ、原音量/节目/监听增益之后，现有左右联动峰值保护之前。控制在运行时以 20 ms 样本时钟平滑过渡，不新增音频缓冲延迟。传输重置保留用户目标设置；滤波器或预设切换不抢断独立的 master 增益坡道。

- 不读取歌曲、时间窗口、对象编号、语音内容或声源响度。
- 不修改 PCM 输入、元数据增益、原 61 点测量、插值、空间线索、床声道或 LFE 的相对输入比例。
- 峰值保护会在余量不足时共同影响完整输出，不能保证任意曲目增加同样的 dB 后动态仍完全不变。
- 现有峰值保护是样本峰值/前视保护；本次导出另行核查 4 倍过采样峰值，未宣称运行时具有任意内容的真峰值保证。

## 接口

- 共享 renderer：`Engine::set_master_preamp_db`、`Engine::master_preamp_db`。
- 原生 JSON 协议：`{"type":"setMasterPreamp","gainDb":2}`。
- 移动端共享 Rust facade：`MobileEngine::set_master_preamp_db`。
- iOS 低层 C 命令：`masterPreamp`，参数 `{"gainDb":2}`。

这里只接入低层控制；没有新增播放器 UI 或保存偏好，也没有将任何正增益设为默认。Android/Windows/iOS 均复用相同 DSP 内核，但本次不是三个平台的打包、安装或实机认证。
