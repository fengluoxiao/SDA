# 声源面积与扩散（实验性）

2026-09-10。入口：系统设置 → 声源面积与扩散。仅接入桌面原生对象渲染，默认关闭；网页独立播放器、立体声与固定声床不使用此处理。

## 使用

- **按母版**：启用处理，最小宽度和最小扩散均为零。没有大小/扩散信息的对象保持点声源。
- **宽声源试听**：最小宽度 30°、最小扩散 12%，供主观对照。这是工程试听预设，不是合唱团的物理参数。
- 两个最小值作用于所有对象，不能自动识别人声、合唱或乐器；不会执行分轨。
- 滑块调整后点击“应用范围”。开关立即应用并保存在本机，原生输出重新启动时恢复；失败不保存新设置。关闭回到原对象渲染。

## 实现与边界

原有处理将解码后归一化的宽、深、高平均为单一 spread；新处理保存三个独立值，沿文件的采样时钟和位置插值同步更新。已有解码器仍负责格式转换，不能把此处的归一化值解释成 ADM 原始角度或实际米数。

展开对象每 512 个采样（约 10.7 ms）重算面积路由，中间连续插值；元数据事件仍按原定采样时间生效。零面积与旁路保留原来的 128 采样路径。面积使用围绕对象中心的对称九点求积，将宽、高分别映射至名义最大 120° 的局部角范围（深度采样可能扩大表观跨度），累积各点的 VBAP 功率后取平方根。深度通过近/远横向样点的表观角范围参与；它不是近场 HRTF 或物理距离衰减，也不是完整体积积分。零宽高直接复用现有点路由。水平约束、区域排除与头部姿态沿用现有规则。

扩散与面积分开：各对象先按扩散权重和音箱路由汇总，再通过每音箱独立的延迟全通滤波器，形成不同的相位响应，再进入现有音箱 HRTF/房间链。全通反馈系数 0.5，延迟 149 + 46 × 音箱索引个采样，属于固定工程选择。相同滤波器的线性叠加允许共用音箱滤波器，避免每个对象重复计算；动态增益在滤波前作用于激励。它用于降低相关性，不添加额外房间模型；不代表完全不相关，也不保证所有频率的单声道叠加一致。

直达与扩散分量使用平方根能量权重，扩散比例变化平滑约 200 ms。不额外归一最终双耳响度或增加输出增益。功率归一不意味着经过不同 HRTF、房间和相关信号叠加后的响度严格不变。面积的直达分量仍为相干信号，并非物理独立的多个歌手；扩散是可调近似，过多仍可能让人声变虚。

逐对象模式保留对象自己的直达卷积，扩散分量送入同一音箱总线；音箱总线模式使用同一面积和扩散规则。低音炮不作为扩散方向。Solo/静音和音箱聚焦继续使用现有处理。

## Touch 检查

文件：Daft Punk / Random Access Memories (10th Anniversary Edition) / Touch.m4a。

按用户指定的 4:30–5:30 和 6:30–7:45 分别检查，并各取约 10 秒预卷。两个区间都识别出 15 个对象（ID 10–24），未观察到非零 size 或 diffuse，解码错误为零。因此“按母版”不会凭空为本曲推断合唱面积，可用“宽声源试听”主动对照。未声称这些对象中的某一个就是独立合唱轨。

后续复核：绕过 WASM 事件桥接，用当前 Rust E-AC-3 有状态元数据解析器从曲首连续读取全部 15,596 个访问单元。两个指定区间分别有 28,125 和 35,160 个动态对象元数据块，均输出 `size=[0,0,0]`，解析错误为零；整首未观察到非零 size。该结果排除了短预卷未继承早期大小状态的可能，但仍是当前解析器的结果，不冒充 Dolby 参考解码器验证。前端对象球即使 size 为零也有基础显示半径，不能从球的可见大小反推母版宽度。

## 验证

- 宽/高产生不同路由，左右对称、功率守恒；零范围退化为原点路由。
- 全通脉冲总能量、通道间相关性、数值有限性。
- 原生实际 PCM：音箱总线和逐对象模式都验证零参数逐样本旁路一致；测试宽度 0.5、扩散 0.25 的合成宽带信号输出能量比约 0.960、差分能量比约 0.357，无隐藏增益补偿。这不是 Touch 的试听结论。
- 最终完整原生回归 104 项通过、5 项忽略；独立运行的性能测试通过。
- `scripts/test/source-extent-ui.test.cjs` 验证应用、持久化、恢复母版、旁路及拒绝时保留设置，不初始化音频输出。
- 本机 release 压力测试：128 个移动对象、9.1.6、宽度 0.5、扩散 0.25，每 100 ms 音频的面积路由与共享扩散计算约 14.06 ms。仅为该模块微基准，不包含解码、HRTF 卷积、事件队列或完整混音负载。
- 性能需结合设备、对象数、HRTF 长度和房间响应评估；不承诺任意设备的实时预算。听者对合唱定位、宽度和单声道音色的验收仍需实际试听。
