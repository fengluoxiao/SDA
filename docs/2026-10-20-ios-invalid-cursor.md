# iOS 压缩音轨 Invalid sample cursor 恢复

设备截图给出了 AVFoundation -11880（Invalid sample cursor），底层 NSOSStatus -12551。远程快照将其记录为 feedError，发生在播放约 292.757 秒、已解码约 295.168 秒时。路由切换/中断发生得更晚，不能据此认定为起点。

对用户此前提供的同名本地文件检查：9270 个 EC-3 样本、每个 3072 字节，stts 共 14238720 个 48 kHz 样本；编辑列表起点 3072，段长 14237954，声明终点比物理样本尾部多 2306 个样本（约 48.04 ms）。这与尾部游标问题相符，但未将本地文件元数据当作设备错误唯一诱因的证明。

旧路径对 -11880 已经会重建 AVAssetReader 并从头顺序读取。新增路径只在这个明确错误后尝试一次：索引同一清晰 EC-3 音轨的 stsz/stts/stsc/stco/co64，校验所有偏移在 mdat 内，并用原先已返回字节的完整 SHA-256 与可用时间戳唯一证明续读位置。编码预卷由原始起点/呈现时间映射候选及前缀验证处理。未经验证不返回新数据；不重置解码器、不重播已有字节、不补静音、不把错误当作 EOF。音轨 ID 始终沿用 AVFoundation 实际选中的 ID。

仅保留 moov/样本索引、哈希状态和一个编码包；没有 PCM 缓存。编辑终点受实际样本表约束，不能虚构尾部数据。复杂多段编辑、外部引用、加密/重排/碎片化等不支持的容器保持原读取路径；索引/前缀验证失败也不替代已有安全重试。ALAC 和原始码流路径不变。

远程诊断新增安全错误分类、允许列表中的错误域/数字码和输入后端/恢复计数/前缀字节数/恢复耗时，仍不发送错误正文、歌曲名或路径。真实恢复记录 compressedReaderRecovered。

生产隔离：模拟器 CI 入口及实现通过 targetEnvironment(simulator) 限制；物理设备 IPA 打包时只删除两份已知 CI 测试音轨，并验证其他资源不受影响。普通设备启动不运行输出自测；正常输出回调的补零只是音频缓冲初始化/缺帧处理，不是额外测试音轨。

验证：原有 Apple 压缩字节/恢复和 ALAC 检查保留；增加 stco/co64 合成容器在 9224 包位置的前缀/尾段逐字节验证、预卷起点、错误哈希与截断拒绝。合成材料来自已有 CI 音调，未上传用户音乐。iOS 模拟器烟测还要求索引恢复字节一致和诊断隐私验证。实体机实际回放仍需安装修复包后复核，不能由源码/模拟器测试代替。
