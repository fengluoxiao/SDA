本轮没有生产增益或EQ改动。上一轮元数据核对属进展，本轮实际检查历史听感参考是否被错误解释成“仅整体放大”。

入口：`scripts/diag-how-love-bounded-reference-fit.py`；输出 `C:/Users/legendshop/Downloads/SDA-clarity-validation/bounded-reference-fit.json`。脚本运行、Python编译检查通过。

## 参考边界

使用compact replay的unity-guard baseline16路，构造历史C master+2、Obj12–24+6，再按8s LUFS匹配当前compact preset。Object ID仅用于复原诊断参考，不是生产语义选择。此compact状态的当前LUFS=-16.16008，与full-prefix试听=-16.17380不相同，不混报两者。

匹配标量=-3.41551dB，参考实际等效：LFE/Obj10/Obj11=-1.41551dB，Obj12–24=+4.58449dB。它仍保留6dB相对组差，匹配整体响度并没有消除重混。

## 常数增益近似

训练前3.9秒，留100ms边界隔离，后3.9秒计算描述性波形残差。给每个对象单独常数增益，是比当前几何规则更自由的诊断模型；不是证明所有动态算法的上界，不是清晰度损失函数。

| 诊断约束 | 后3.9s波形残差相对参考 dB |
|---|---:|
| 当前compact几何方案 | -12.5553 |
| 每对象仅允许0～+1.5dB，LFE unity | -13.2561 |
| 仅0～+3dB | -14.9722 |
| 仅0～+6dB | -16.1720 |
| 允许诊断衰减/提升，LFE仍unity | -50.1494 |

无约束拟合自然接近历史主层衰减约-1.45、辅助组约+4.6；不采用该拟合，因为它按歌曲/对象决定增益，且超出已认可的当前声源范围。

结论：当前上限与“不压主层”的前提不能被当作已经原样复刻C的依据。不能用这个波形拟合证明目标清晰度只能通过更大增益改善，也不据此扩大生产增益。目标仍是寻找通用清晰候选且不破坏三首，而不是将目标换成C波形匹配。残响-12候选已交试听但未接受，当前不叠加更多猜测性处理。
