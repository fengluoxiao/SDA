# 后方声源移动、HRTF 与空间平衡检查（2026-11-14）

本记录描述最初的检查，当时仅增加诊断和回归测试，没有修改生产音频算法、资源或默认增益。后续修复见[空间平衡中频保护修复](2026-11-14-spatial-body-protection.md)。

## 结论

当前合成场景中，后方对象的实际渲染方向正常更新，空间平衡开关前后的各频段左右声级差基本一致。最明显的音色变化来自空间平衡的源级频谱重分配：较弱的后方声源在约 1 kHz 处衰减约 3.6 dB，而 6 kHz 提升约 2.1 dB。它可能使以后方中频为主的移动声部变薄；这不是已经证明的所有歌曲或设备上的听感结论。

## 条件与范围

- 使用正式打包脚本选中的共享 542 方向 SDA Spatial 资源，包含现有 shared depth / clarity 配方。
- 48 kHz，两个单声道对象，固定源增益、固定单位距离、零扩散和宽度；后方对象在 110° 至 250° 之间移动，前方对象作为更强的参考。
- 后方标记频率为 250、1000、3000、6000 Hz；前方参考使用不同频率，避免把前景电平当成后方输出。
- 7.1.4 与 360RA-13 两种布局，空间平衡开关、残响开关共八组实际原生 PCM 渲染。另比较两套对象混音路径。
- 使用低电平，逐块确认峰值保护未介入、距离增益为 1、对象方向跟随元数据；本场景遮挡目标均为全开。
- 方向响应另以 0.5° 步进扫描整圈，覆盖水平和抬高 30°，比较有无共享 clarity 的响应。共 2884 个响应，包含同方向的不同处理条件。

## 测量

以下为空间平衡开相对于关的后方标记变化，取 1.2–3.0 秒的 100 ms 加窗测量。两种布局结果接近。

| 后方频率 | 7.1.4 变化范围 | 360RA-13 变化范围 |
| --- | --- | --- |
| 250 Hz | +0.118 至 +0.120 dB | +0.118 至 +0.120 dB |
| 1000 Hz | −3.664 至 −3.637 dB | −3.664 至 −3.637 dB |
| 3000 Hz | +0.583 至 +0.591 dB | +0.583 至 +0.591 dB |
| 6000 Hz | +2.077 至 +2.083 dB | +2.077 至 +2.083 dB |

同一频率左右声级差在开关前后的变化低于 0.001 dB。本测试中四个后方标记的合计输出能量变化约为 −0.30 至 +0.51 dB；因此不能将 1 kHz 的衰减解释为整个后方音量降低 3.6 dB，也不能据此断言整曲 LUFS 不变。

HRTF 后方区间相对于最近测量方向的宽带能量变化：水平约 −0.46 至 +0.30 dB，抬高 30° 约 −0.39 至 +0.45 dB。最近方向是参考，不是插值真值或感知误差标准。后方 1 kHz 相对最近方向的最低偏差约 −0.12 / −0.24 dB，未观察到与空间平衡同量级的中频塌陷。

移除现有残响后，空间平衡造成的中频变化仍然存在；残响会改变部分频率的左右差异，但本场景中不是上述约 3.6 dB 衰减的主要来源。

## 原因与既有测试覆盖

`directional_detail::SourceState::process` 将信号分成互补的低频和高频，增强高频中的细节后，用能量归一化系数乘整个高频分支。该分支从 250 Hz 开始，因而在提升较高频率时也可能压低中频。

原测试验证了 80 Hz 低频、3 kHz 细节和整体能量，没有限定 1 kHz 的变化。因此原测试通过不能排除中频变薄。新增测试验证实际移动方向、频段左右差异和两套混音路径一致性，不把当前的中频衰减当成期望行为固定下来。
