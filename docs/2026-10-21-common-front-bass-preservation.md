# 前方人声清晰处理保留低频

真实源：天球(そら)のMúsica，E-AC-3/JOC，15 路对象加 LFE，280.352 秒。所有比较从曲首连续解码与渲染，重点测量 235 秒至结束。

现版空间平衡开启后，在音量平衡开启时，20–120 Hz 比空间关闭低 2.266 dB，120–350 Hz 低 1.784 dB。只旁路前方共通声部处理、保留其他空间处理，低频差异仅约 -0.004 dB，因此问题定位到前方清晰处理。

原处理将共通成分全频重整到中央，宽带参考未计入实际存在感滤波。修正使用 500 Hz 因果互补分频，保留低频的原始前方路线，只重整中高频共通成分；原有 3 kHz/+3 dB 存在感滤波保留。参考核包含实际存在感滤波的响应，以免未计入的能量再次触发共同衰减。差分声部、播放采样时钟、+2 dB 节目补偿与最终响度／真峰值保护继续工作。没有按歌曲或对象编号分支，也没有固定低音增益、播放预扫或新增歌曲缓存。

低频已接近关闭参考；120–350 Hz 仍有约 0.9 dB 差异，不把它描述成全频逐点相同。34 项相关原生检查通过，覆盖互补分频、存在感参考、声像、分组不变性、回调分块、重置、原有共同输出保护。六种试听组合的位置、播放与暂停切换检查通过；24-bit WAV 与对应原生整曲的同一位置逐样本核对通过，只有量化误差，没有逐片段响度归一化。

诊断重放工具与当前渲染运行时代码一致，仅在私有构建副本禁用无关测试模块以缩短编译。全部原生检查在原始源码工作区运行。以上为本地离线测量与浏览器验证，不代表手机实机听感确认。用户已认可该保低频修正并要求合入、推送及打包；随后要求节目输出补偿由 +2 dB 调整为 +2.5 dB。上表保留为已认可的 +2 dB 试听测量，新补偿仍使用共同输出保护。
