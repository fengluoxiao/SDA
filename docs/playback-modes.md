# 播放循环模式

迷你播放器和播放列表底部共用播放模式按钮，点击依次切换：

- 顺序播放（默认）：自动播放下一首，列表末尾停止。
- 列表循环：最后一首结束后回到第一首；只有一首时重复该曲。
- 单曲循环：当前歌曲结束后从头重播。

模式保存在本机，重开软件后恢复。播放中切换模式不打断歌曲，曲末使用最新选择。清空列表或移除当前歌曲后，不会通过旧的结束通知重新启动列表。重复或过期的结束通知不会重复切歌。

循环复用现有文件加载和解码流程，不保证无缝衔接。

验证：`node scripts/test/playback-order.test.cjs` 覆盖列表边界、单曲列表、存储不可用、播放中切换、过期及重复结束通知、清空列表。另以静音浏览器检查两个入口同步、空列表入口和刷新后恢复；TypeScript 检查与生产构建通过。
