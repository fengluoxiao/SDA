# 空间平衡辅助层余量修复

用户指出空间平衡开关在大多数歌曲中听起来接近。实测增益轨迹显示，部分歌曲的辅助层增益长期接近 0 dB，不能仅用“方向已覆盖”说明真实歌曲已有足够的空间增强。

## 修复

最终输出控制器原先用衰减前的混音电平计算可用余量。存在共同输出衰减时，这会再次扣除已经处理过的过响部分。现在将实际生效的衰减包络计入余量，基于控制后的混音电平反馈。

辅助控制器原先直接把整个混音的 dB 余量当作辅助源的增益余量，并固定再扣 1 dB。现在根据当前前方/辅助能量及已生效的辅助增益，计算辅助信号在参考幅度和中的占比，把整段混音预算转换为该辅助组的增量预算。采用幅度相加的保守估计，另保留 0.2 dB 混音余量；这不是固定辅助增益或按歌曲硬编码的目标。

弱辅助内容的增益仍由实际相对能量缺口确定；测量不足、静音或无可靠余量时不额外增强。正增益仍最多每秒增长 0.25 dB，过强辅助内容沿用动态削弱。前方源保护、主唱清晰度、HRTF/深度配方、杜比专用最终补偿以及真峰值保护保持原路径。没有新增整曲扫描、音频缓冲或歌曲缓存。

该控制适用于共用源处理入口的声床和对象，不按 360RA / Audio Vivid / AC-4 / JOC 分别打补丁。它依然按辅助组共同调整；已经均衡的片段不要求强制产生正增益。

## 验证

新增回归证明：控制后已经处于目标附近的输出，不再被报告为仍有十多 dB 的原始过响；0.8 dB 的整段混音余量可以用于增强实测偏弱的辅助组，四秒后有大于 0.7 dB 的平滑增强，而不是直接返回 0 dB。

40 项共享渲染器定向检查通过，覆盖辅助控制、最终输出、受控余量、快慢对象/声床路径、前方基准、任意回调分块、头部姿态和模式切换。连续真实源场景的开关矩阵及独立响度/真峰值测量记录位于工作目录外 `SDA-spatial-headroom-fix-20261020`，与最终包一同核对。

这些是本地开发验证，没有加入设备打包流水线。实体设备的最终听感须与源级数值及包完整性检查分开记录。
