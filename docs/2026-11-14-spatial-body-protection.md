# 空间平衡中频保护修复（2026-11-14）

此前的[后方移动检查](2026-11-14-rear-motion-audit.md)发现，源级细节增强会用中频能量补偿高频提升。在较弱的后方声部中，约 1 kHz 的成分可能因此衰减约 3.6 dB。本次修改针对这段处理。

## 修改

`directional_detail::SourceState` 继续计算原有的、能量归一化后的细节候选输出，增加源级中频保护：

1. 采样率配置时，根据实际使用的两个滤波器系数，计算 80–2000 Hz 的保守响应边界。
2. 实时处理时，根据当前平滑后的增强量和归一化系数，估计该频段可能承受的最大衰减。
3. 如果超过保护限度，按比例将增强候选混回原始信号。保护目标为 0.45 dB，回归测试上限为 0.5 dB，给配置采样点之间的频率留出余量。

保护同时考虑滤波器的复数响应，避免只看各分支能量、漏掉相位造成的凹陷。它会减少增强量，不用额外的整源增益补回被削弱的中频。原有的能量归一化仍然保留；混合是凸组合，没有加入第二个响度控制器。

每个源仅增加三个响应边界标量；频率扫描只在采样率配置时执行。音频循环没有增加分配、文件读写、整曲分析或缓冲延迟。

HRTF 测量数据、插值、对象坐标、残响、遮挡、前景保护、手动音量和格式增益策略没有修改。该修复位于桌面与移动端共用的原生渲染器中。

## 同条件对比

使用与此前检查相同的低电平、恒定距离后方对象，110° 至 250° 移动轨迹、较强前方参考和 48 kHz 输出。测量 1.2–3.0 秒的后方标记，以下均为空间平衡开启相对关闭的结果。7.1.4 与 360RA-13 两种布局结果接近。

| 频率 | 修改前 | 修改后 |
| --- | --- | --- |
| 250 Hz | 约 +0.12 dB | 约 +0.001 dB |
| 1 kHz | −3.66 至 −3.64 dB | 约 −0.408 dB |
| 3 kHz | +0.58 至 +0.59 dB | 约 +0.14 dB |
| 6 kHz | +2.08 dB | +0.72 dB |

同频率的左右声级差开关变化仍低于 0.001 dB。源位置继续跟随元数据，两套对象混音路径一致。

较低的高频提升是保护中频的预期代价：不能一边要求保持源能量、一边不加限制地要求高频大幅提升。新的测试保留正的细节对比要求，同时限制中频损失。源级多频信号的能量变化约 −0.006 至 −0.051 dB；经过 HRTF 和已有输出处理后，本移动场景中四个后方标记的合计输出能量变化约 +0.01 至 +0.22 dB。这些不是整曲 LUFS 测量。

## 回归验证

- 新增中频测试在旧实现上失败，复现 500 Hz 约 −2.11 dB 的过度衰减；修复后通过。
- 44.1、48、96 kHz，均衡、偏低频、偏高频三类多频输入，分别检查 80、250、500、1000、2000 Hz、电平能量和细节对比。
- 在配置扫描点之间密集检查频响保护，对不同增强量和归一化系数检查 0.5 dB 衰减上限。
- 检查开启后关闭恢复精确旁路、非有限输入、采样率变化、128 个源、源拆分、幅度缩放和左右比例。
- 原生移动轨迹与声级差检查覆盖两种布局、两套混音路径；另比较空间平衡及残响开关的八组 PCM。
- 进一步验证共享 HRTF 配方、前景保护、输出电平策略、移动端音量/空间平衡开关独立性，以及非测试配置的编译。

以上 36 项针对性测试及非测试配置编译检查已通过，另完成八组原生 PCM 对比。两项需要本地歌曲素材的历史离线回放测试未运行。

独立优化编译的 Windows 微基准中，108 个源处理 1024 帧的这段源级处理从约 1.17 ms 增至 1.58–1.63 ms，新增约 0.41–0.46 ms；这不包含整个渲染器，也不代表手机性能。

这些验证不替代实体手机和具体歌曲上的复听。安装包的构建与发布结果单独记录，不作为这些本地测试已在设备上验证的证据。
