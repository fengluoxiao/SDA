# 移动端进度条交互

iOS、Android 与备用布局共用同一套进度条手势。轻点松手直接定位；按住时进度条轻微放大，拖动时进度与时间跟随手指，松手只向原生播放端提交一次定位。拖动预览不改变原生播放时钟，也不重复打开或重新分析歌曲。

手势始终使用触摸起点加水平位移计算位置，填充条不单独接收触摸，避免触点位于已播放区域时坐标变成子视图坐标。拖出左右边界分别定位到开头和结束前；系统取消、多点触摸、切换歌曲、时长变化或屏幕宽度变化会取消预览。

相关回归：`node --test apps/mobile/test/progress-scrubber.test.cjs`。测试执行实际共享 Hook 的手势回调，覆盖保持预览、拖动、单次提交、播放轮询、边界、取消及两处界面绑定。代码回归不能替代安装后的真机触摸体验验收。
