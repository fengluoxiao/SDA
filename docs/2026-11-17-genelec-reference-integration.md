# SDA Spatial 统一处理链

更新：2026-11-17。版本 0.9.40，移动端构建号 951。

界面与预设名称只保留 **SDA Spatial**。此前新增的独立参考监听室选项已撤掉；旧选项保存值不再激活独立处理。四个平台从相同的共享 HRTF 配置进入同一条原生处理链。

## 合并内容

保留原有直达 HRTF、连续对象定位、头部追踪、retained61 短反射、空间平衡和已修复的余量增益。在同一个反射库中叠入根据归一音箱方向性与假设房间生成的固定残差，每个声道仅加入一次。没有用新的房间替换已有短反射，也没有靠改预设名称实现切换。

普通 2.0／2.1 立体声继续使用既有路径。空间布局覆盖 Atmos、360RA 三个底部声道及其他已有多声道布局；LFE 保持独立。固定系数编进原生库，不增加歌曲缓存、整曲等待或 JS 音频桥接。

当前共享资源用 `sharedReferenceVersion: 1` 标记统一处理。未含此标记的旧 SDAR 自包含资源仍按原来的处理版本播放，防止旧母版被额外叠加新残差。导出当前 SDA Spatial 时，标记随共享响应资源一起保存。

## 数据与适用边界

数值来源和假设保存在 `apps/native-renderer/assets/genelec-reference/NOTICE.md` 与 `manifest.json`；离线生成器为 `scripts/build-genelec-reference.py`。来源为厂家公开 GLL 归一方向性，采用幅度推导的最小相位近似、假设 6×5×3.2 米房间及一／二阶镜像反射，并使用已有共享 HRTF 接收。没有获得完整音箱轴向绝对低频、房间模态或低音炮实测响应。

因此这里只说明实际合入的处理，不把它命名成 The Ones 听感或宣称已复刻实体音箱。听感仍需实际试听；没有通过额外固定低频增益冒充音箱特征。

## 验证与打包

本轮验证统一名称、唯一预设、旧选项退出、原短反射保留、新残差只叠加一次、直达响应保持、声道布局与 PCM 时钟保留、普通立体声路径和自包含资源版本标记。真实歌曲 PCM 用于检查合并后的输出差异、低频、响度与真峰值，不能代替真机试听。

打包同时修正两项上一轮发现的问题：Android 来源记录必须显式读取 UTF-8；原生算法标识以实际静态字符串参与准备，防止 macOS x64 优化把短字符串拆为指令常量，造成打包的二进制标识检查误判。保留 Windows ARM64 月末编码器归档及架构校验。


本轮结果：575 项渲染回归、176 项原生播放器回归通过；iOS 9 项资源检查、Android 2 项来源清单、桌面 6 项包校验及四端共享资源一致性、移动与桌面类型检查通过。三段真实 E-AC-3/JOC 输出完整，未启用独立监听模式；独立测得真峰值为 −5.5、−4.7、−5.7 dBTP。相对原 SDA，20–80 Hz 分段能量变化约 +0.15 至 +0.22 dB，80–200 Hz 约 −0.21 至 −0.09 dB。这是实际测量结果，不等于真机主观听感已经验收。
