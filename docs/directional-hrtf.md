# 连续方向 HRTF

2026-09-10。系统设置 → 连续方向 HRTF → 按对象实际方向渲染。实验性、默认关闭，独立于原“逐对象 HRTF”开关；开启会自动使用逐对象路径，关闭恢复原选择。

## 音频路径

旧逐对象模式为每个对象维护独立卷积，但滤波器仍由虚拟扬声器 HRTF 混合而来。新模式使用对象实际方向，在当前 HRTF 数据集中插值得到直达声：

`每个对象：短连续方向直达滤波器（近场只作用于这一路）`

`公共反射总线：先按采样时刻的扬声器路由汇总对象输入，再卷积（原扬声器房间滤波器 − 原扬声器直达滤波器）`

反射卷积数量取决于布局的扬声器数，不再为每个对象重复计算长房间卷积。固定路由时利用卷积的线性性质合并，和独立对象参考路径做 PCM 对照；运动时保留发声时刻的反射发送方向，旧反射尾声不会被新位置重新转向。

声床、LFE、音量与峰值保护沿用原路径。近场直接处理短直达声，因此不会重复修正或把房间反射近场化。声源面积使用同一九点对称范围采样，重合采样点合并权重后只计算一次；每个范围采样点都接受头部姿态旋转。扩散仍经过现有去相关扬声器总线。

保留扬声器静音、监听增益/延时/反相、校准和聚焦控制。对连续方向直达声使用现有路由的能量权重传递这些控制，而不是重复叠加相同方向信号；无校准、无反射的单位能量对象直达声不应随虚拟布局变化。实际 HRTF 样本不做额外响度归一。与旧模式切换时音色、响度可能不同，不能把更响当作更准确。

## 插值与时序

使用单位球弦距、局部紧支撑 Shepard 权重。支撑半径由第八近邻确定；同距离邻居全部纳入，边界权重连续趋零，测量方向处保留原样。每耳按测量脉冲绝对峰值对齐，混合对齐后的波形，再恢复加权到达时间；使用线性分数采样延时。双耳延时分别插值，因此不会直接抹除 ITD。

峰值对齐是工程插值方法，不是严格的生理到达时间估计。分数延时有频响误差，尤其高频；密度不足或相邻测量差异较大的区域仍可能产生音色变化。这不是新增实测数据，也不是已经验证优于苹果空间音频的结果。

方向目标随原生卷积块更新，滤波器在相邻块间交叉过渡，保留卷积历史；当前块长沿用原生 DEFAULT_PARTITION。只在方向/范围/路由变化或静音恢复时重建，静止对象复用滤波器。FFT 计划复用，零填充的滤波器分区跳过 FFT。反射差值按扬声器缓存，独立对象的滤波器生成并行执行；分数延时以两次连续数组累加实现，避免逐采样取整和边界分支。未启用的聚焦滤波不执行；没有独立校准/监听控制时，同一干声的路由标量只累加一次。

连续模式的新对象不创建旧长卷积和额外近场参考。已有对象切换时保留 200 ms 输入交叉过渡和完整旧尾声，完全静音后释放旧路径。FFT 计划在对象间共享；左右耳滤波器打包为一次正 FFT，左右耳输出打包为一次逆 FFT，再解包恢复各自的频谱/PCM，保留双耳独立性及逐采样交叉过渡；近场静音状态归零，避免极小浮点数拖慢处理。短滤波器的背景滤波尾部预留 10 ms，避免纯零填充多占一个 FFT 分区。

满足条件的连续对象按对象连续处理采样，在现有工作线程池中分组计算；每组使用独立输入缓冲，全部完成后按固定组序汇入公共总线，减少跨轨缓存切换且不争抢总线。元数据、增益、可用性渐变仍按原采样时钟更新；公共扬声器电平和聚焦渐变逐采样预计算，对象活动快照保留原时间戳。声床、区域排除、低频管理及尚未结束的旧路径切换使用通用混音路径。

## 兼容与边界

- 普通立体声与固定声床不变。不能解码出独立对象的 AC-4 IMS 等内容不会凭空变成对象。
- 使用当前所选 HRTF，包括个人档案；稀疏个人档案不能由此变成密集实测档案。原个人档案运动测试使用扬声器 VBAP，不能视为新模式的运动定位验证。
- 带区域排除的对象继续使用原扬声器路由，避免连续方向重建绕过母版限制。
- 硬件仿真启用时仍使用硬件扬声器链；界面显示原因。
- 大范围干声是相干声源采样，不等于分离出的独立歌手或乐器；相干范围展开可能改变音色。
- 可以在未播放时保存开关；HRTF 未配置时原生也接受设置，播放就绪后生效。保存键为 `sda-directional-hrtf-v1`，输出启动时恢复。

新增混音对照包含 16 对象与声床、宽度/扩散、移动、扬声器渐变、区域排除、增益事件、静音/恢复、缺失 PCM、不规则音频块和移除事件。并行路径与通用路径的最大 PCM 差异限制为 2e-6，同时核对位置、路由增益、缺失采样计数、路由更新计数和活动快照，避免只跑性能而漏掉时序问题。
