# 连续播放后的输出保护恢复

最终输出保护的累计响度参考可能将后续较轻片段排除在相对门限外。此前，响段触发的共同衰减持续作用于这些轻声片段；数字静音又直接保持旧衰减。连续信号复现中，轻声—响段—同一轻声序列在 20 秒后仍多衰减约 7.1 dB，静音后仍衰减约 7.8 dB。

现在保留累计节目参考，但历史响度导致的衰减还必须有当前短时响度支持。当前片段已低于参考时，用既有的 3 秒释放包络撤销旧衰减；数字静音也执行释放。瞬时响度约束、共同左右增益、节目音量增益、+2 dB 格式校准和最后真峰值保护继续工作。暂停状态不处理音频帧，因此没有通过重置检测器改变暂停／继续行为。

回归检查覆盖 +1.5/+2 dB、轻声重现、静音后的重现、释放连续性，以及四类选定格式在空间平衡两种状态下的实际最终输出。固定节目增益以隔离保护器的旧衰减，不通过冻结实时音量平衡或添加整曲扫描／缓存规避问题。

验证结果：11 项控制器检查和 14 项最终输出检查通过。相同连续信号中，+1.5 dB 时轻声重现的额外衰减从约 −7.07 dB 恢复到 −0.016 dB；+2 dB 时恢复到 −0.017 dB；静音后的旧衰减从约 −7.79 dB 恢复到 −0.018 dB。这些是本地连续信号与渲染器输出验证，不是特定曲目或手机的实测。
