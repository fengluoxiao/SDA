# SDA Spatial 三项声音增强

本轮用户明确授权“实装三项增强处理，允许调整听感”。承接 991 的声音修复和上一轮坐标修复；本轮实际新增 DSP，不再只作审计。由现有“空间平衡”开关控制，不新增渲染品牌或独立模式。

## 研究与实现的关系

| 方向 | 依据 | 实际新增处理 |
|---|---|---|
| 小幅转头与前后辨识 | [McLachlan 等，2023](https://doi.org/10.3389/fnins.2023.1027827)；[时间预测研究](https://doi.org/10.17743/jaes.2022.0195) | 原生姿态携带采样时间和 iOS 输出延迟，结合已排队音频与分块延迟估计呈现时刻的偏航。最大预测时域 80ms、角度 ±6°；停头收敛，反向重估，回中/重置清除速度。保留测量姿态，不学习新的原点。 |
| 先到声与反射 | [Litovsky 等，1999](https://doi.org/10.1121/1.427914) | 保留直达滤波，仅用已有反射残差总线替换原有反射激励，额外延后 1ms；瞬态期间短时降低反射激励，最低为原来的 0.55，随后恢复。 |
| 声源宽度与包围感 | [Bradley、Soulodre，1995](https://doi.org/10.1121/1.411951) | 连续 HRTF 使用独立的元数据宽、高、深，保留仅有 scalar spread 的格式兼容。宽度响应以同一个双耳标量补偿相干抵消，最大 2 倍，不分别归一化左右耳。环境包围声使用单独的世界坐标发送、180Hz 高通、80ms 延迟和固定全通扩散，再经现有 HRTF 输出。 |

研究提供处理方向和检查方法，并不直接给出上述代码参数。80ms、±6°、1ms、0.55、宽度曲线和 -20dB 晚场发送均是本项目的受限工程选择。新增晚场是人工环境增强，不声称恢复录音中缺失的原始房间，也不声称单元测试证明了个人前后定位能力。

## 信号路径与边界

- 普通 SDA 双耳渲染且空间平衡开启时生效。SDAR 已制作处理、硬件模拟、非双耳输出旁路新增处理；Apple 系统空间输出不进入此自有渲染链。
- 主扬声器核为 dry + residual，反射核为 residual。新的残差激励为 `delay(gate * (main + reflection))`；反射总线加入与原激励的差值。因此实际合成保留 `dry * main`，没有重复添加直达声，也没有为每个对象增加新卷积器。
- 前方主声源不发送晚场，LFE 和静音源不发送。发送资格来自世界位置的平滑权重，转头不把前方人声重新归入环境组。360RA 底部声道继续使用该布局的实际扬声器方向。
- 晚场在世界坐标中保留历史，输出时逆转头部姿态。焦点/静音扬声器电平仍作用于晚场输出；原有最终电平检测和峰值保护看到合成后的完整 PCM。
- 新增固定 DSP 状态：48kHz 下延迟/扩散约 388KiB，另有约 88KiB 总线帧缓冲，以及每个对象混音工作缓冲约 88KiB。状态不随歌曲时长或播放列表长度增长。无落盘歌曲缓存、无整曲预分析；seek/切歌重置、完整关闭后重新开启会清除延迟历史。
- 关闭空间平衡恢复原有宽度映射，零面积声源保持原响应。宽度与晚场分别控制，避免以宽度替代环境包围感。

## 验证

针对性检查在本地运行，与 GitHub package-only 流程分离：

- 真实扬声器总线/卷积的已知脉冲：直达脉冲不变，原反射被替换，新反射在原位置后 48 个采样出现且幅度为 0.55 倍；其他位置无重复脉冲。
- 小角度转头、角度环绕、反向、停头、过期包、追踪重置、启动时早于渲染器创建的传感器时间；带时间姿态合并保留最新时间，重置是队列边界。
- 独立宽高深、零面积精确旁路、双耳使用同一宽度补偿；实际增强 PCM 与关闭时不同。
- 实际输出分块一致性、对象快慢路径一致性、前景/LFE/静音晚场排除、80ms 前无晚场、有限能量、seek 与重新开启无旧声音。
- iOS-host 原生 Rust 接口的本地编译检查、三端设置说明 TSX 语法检查、打包来源记录输入检查。

优化编译最终结果：24 项定向检查通过，0 失败，包括单独运行的性能基准。实测 HRTF、108 源、48kHz、1024 帧（预算 21.333ms）的 Windows 本机结果：

| 空间平衡 | 平均 | P95 | 最大 |
|---|---:|---:|---:|
| 关闭 | 11.112ms | 16.917ms | 18.788ms |
| 开启 | 11.919ms | 16.638ms | 20.530ms |

平均增加约 0.807ms。P95 的轻微反向差异是本机运行波动，不解释为增强加速。合成信号的最终增强/关闭 PCM 相对差异 RMS 约 11.9%，只证明实际声音处理生效，不是主观改善比例。

Windows 模型性能检查不是 iPhone 真机测量；没有实体耳机听测、真人定位成绩或主观听感保证。IPA 打包只编译和核验设备包，不执行上述测试集。

运行状态与包来源记录使用 `microturn-precedence-envelopment-v1`，可核对真正编入这三项处理的版本。
