# 空间开关共用最终输出基准

用户反复指出开启空间平衡会比关闭小声。此前最终响度控制器仅在空间平衡开启时工作，关闭端的较大电平与开启端的受保护电平并非同一基准。增加杜比补偿、修正辅助余量都没有独立解决这个开关耦合。

## 当前处理

在 SDA 双耳渲染通路中，开启、关闭空间平衡均持续使用相同的最终输出保护。空间开关只改变源层辅助控制、前方清晰度及既有频响处理，不再重启最终响度测量或切换共同衰减。硬件监控与人头旁路继续使用原有边界。

共同检测参考为 -19.2 LUFS，向应用要求的 -18 LUFS 输出验收线上保留余量；真峰值保护继续为 -1.2 dB。杜比的额外 +1.5 dB 仍由音量平衡和空间平衡共同开启条件控制，其实际结果受同一保护约束，检测目标不再随这项补偿另行抬升。

音量平衡的中性节目测量、只衰减策略及独立开关保持原逻辑。关闭空间平衡时，原先未受同等最终保护的过响输出也会收敛；这项校准不会被描述为单纯把开启端无限加大。没有新增整曲等待、第二遍解码、歌曲缓存或音频缓冲。

## 验证与记录

新增回归对相同最终混音反复切换空间开关，确认逐样本输出相同、响度包络与参考连续。其余输出、辅助组、空间模式、暂停续播检查一并进行，移动端设置说明同步为共用响度基准。

28 段连续源场景矩阵按四种音量/空间开关组合重测，包含 E-AC-3 对象、360RA、Audio Vivid 对象与声床，以及历史回归片段。此次对空间关闭端也执行同一响度/真峰值验收，不能再用未经保护的关闭端作为音量优势。详细测量、开关响度差和最终来源记录在工作目录外 `SDA-shared-output-reference-20261021`。

较弱辅助内容仍按实际缺口、可靠测量和可用余量平滑增强；均衡片段可能保持 0 dB。能量轨迹不等同于每个对象的听感清晰度，实体设备听感须另行验证。仅采用软件验证通过的最终提交重新生成设备包，旧的空间专用保护包属于被替代产物。
