# MiniPlayer refraction

The glass background uses Chromium's SVG backdrop displacement filter, separate
from the player controls. The image is refracted, not merely blurred.

GlassRefraction builds an RG displacement map from the rounded rectangle's
signed distance and outward normal. A smooth bevel profile bends the outer
40 CSS pixels (capped at 48% of the panel height), with zero-slope transitions
and a reduced 18-pixel displacement scale; the centre remains approximately neutral. This is a screen-space
lens approximation, not a physically traced optical material.

The map is regenerated by ResizeObserver only when the surface changes size.
Its width is capped at 1200 pixels. Chromium applies the filter to the current
composited backdrop, including the live Three.js canvas. There is no per-frame
canvas readback, backend IPC, or audio-thread processing. WASM would not remove
the compositing cost and is unnecessary for this infrequent map calculation.

SwiftShader mode retains transparent highlights without displacement to avoid
adding software rasterization cost during audio playback.

Reference: https://github.com/rdev/liquid-glass-react (MIT), especially its use
of SVG displacement for backdrop refraction. The map generator here is an
independent, size-aware implementation; no upstream source/assets were copied.

Verified in Chromium with the real MiniPlayer component over an animated
Three.js grid: 1280 and 390 pixel viewports, dark and light themes, frozen
backdrop comparisons with displacement on/off, live background updates and
stable map data between animation frames. Audio-load performance has not been
benchmarked by these visual checks.
