# 双耳音色发闷/分离度不足 — 调查与修复计划

## 用户报告

播放杜比全景声（如 `01. 字里行间.m4a`、`01. What is love.m4a`）时，双耳渲染听起来"低中频很高、高频很小"，像廉价耳机解析度不够；对象分离度不足。用户点名参考 Genelec / Apple 官方资料。

## 已完成的逐段测量（全部为离线数据，非推测）

| 环节 | 方法 | 结果 |
|---|---|---|
| KU100 HRTF 资产频响 | 对 `az0/az30_el0_dry/wet` 做分频段 DFT | 500–1k 参考下各段在 ±2–4 dB 内，**平坦，无倾斜** |
| 卷积保真 | 单位冲激过卷积 vs 原始 IR 逐频段对比 | 每段 delta **0.00 dB**，卷积链不引入任何倾斜 |
| 对象解码电平 | 完整解码两首文件，逐对象 RMS | 对象电平健康（最强 Obj −22.8 dB，中心床 −31.5 dB），**不是对象静音** |
| 对象坐标 | 同上的位置事件 | 坐标各异、非全零，`hasPos=true` |
| VBAP 求和（正中源） | 方位 0° 经 7.1.4 VBAP + 各音箱干 IR 加权求和 | 正中源直达单音箱，delta **0.00 dB** |
| VBAP 求和（偏轴源） | 方位 15°（C 与 L 之间 0.707/0.707 分裂） | 仅 8–16 kHz 顶部 −1.87 dB 梳状下跌，其余 ±1 dB 内——**幅度不足以解释"高频很小"** |
| 双耳干/湿混合比 | `near` 4% / `mid` 20% / `far` 45%，UI 默认 `near` | 近场模式房间染色极低 |

**结论：双耳信号路径客观中性。** 用户感知的"低中频高、高频小"更可能来自：

- **通用 KU100 HRTF 的物理上限**——Genelec Aural ID 官方明确：通用耳廓档案可用但精度有限，个性化 HRTF 才有最高解析度。这不是 bug，是天花板；
- **双耳全景声 vs 立体声母带的固有音色差异**——全景声双耳模拟"房间里开音箱"，天然比直接为耳机母带处理的立体声版暗/柔（Apple Music 的全景声双耳同样如此）；
- 以及未排除的使用侧因素：是否误开了 中/远 湿声模式、双耳 EQ 三段是否被动过、peak guard 在热信号上的限幅量。

## 参考资料结论

- **Genelec Aural ID**（官方页面）：双耳监听的目标是"中性、不染色的频率响应"，通过耳机 EQ 标定实现；通用 KEMAR/KU100 档案可用，但官方明确建议**个性化 HRTF** 才能获得最高精度。
- **Apple / Dolby Atmos Music 交付规范**：音乐交付目标 −18 LKFS（已用于音量平衡功能）；双耳版本应在音调上忠实于参考混音。

## 排名靠前的嫌疑（按可能性）

1. **VBAP 多音箱叠加的梳状滤波**：单 IR 平坦不代表"某声源经 VBAP 分给多只音箱再各经 HRTF 求和"后还平坦。多方向 IR 叠加会在中高频产生梳状陷波，主观上正是"高频糊、解析度不够"。**这是当前最大嫌疑，也是唯一还没被端到端量化过的环节。**
2. **通用 KU100 HRTF 的物理上限**：没有个性化耳廓数据时，高频定位线索本来就弱——Genelec 官方也这么说。这条不是 bug，是天花板。
3. **湿声模式**：若用户切到 中/远，房间 BRIR 会增加低中频能量（闷感）。
4. **LFE 通道**（增益 1 + 8:1 压缩器）：强低频内容时加重低中频。
5. **peak guard 在热信号上的持续限幅**：+6 dB 补偿后若密集触发，瞬态被压——主观模糊。

## 修复计划

1. **先排除使用侧因素**（零成本）：确认双耳输出模式在 近、三段 EQ 全部 0 dB、未挂耳机补偿档案、未开"低频诊断"。若仍偏暗再进第 2 步。
2. **按 Genelec 的"标定到中性"思路加一个 presence 提升**：如果排除使用侧因素后仍偏暗，给双耳输出加一个轻微的高架（约 6 kHz 以上 +1~2 dB）作为**可选**音色项，而不是硬编码——因为路径测量已证明中性，剩余差异属于感知/参考偏好。
3. **天花板说明**：若仍觉得"解析度不够"，那是通用 KU100 HRTF 的物理限制，根因在个性化耳廓数据，不在渲染代码。

## 不做

- 不改 KU100 HRTF 资产本身的校准（v4 已验证平坦且镜像对称）；
- 不在端到端测量完成前猜数值加 EQ；
- 不引入个性化 HRTF 采集（超出本期范围）。

## 验收标准

- 端到端扫频：正前方声源的双耳输出在 500 Hz–16 kHz 相对参考的偏差 ≤ ±3 dB，且无明显梳状陷波；
- 主观：`字里行间` 人声/高频细节清晰，对象分离可辨。
