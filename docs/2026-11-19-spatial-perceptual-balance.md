# SDA Spatial：频段掩蔽、起音保护与个人试听

保留一个 **SDA Spatial** 名称与预设。新原生算法标识为 `perceptual-mask-transient-measured-headroom-v3`，移动端 0.9.40 构建号 952。

## 自动空间平衡

- 从处理前、场景坐标系下的前方／辅助声部参考，分别测量约 1.8–5 kHz 与 5 kHz 以上的掩蔽证据。控制滤波器并非砖墙分频，邻带仍有过渡。前方低频强不能单凭总能量触发高频细节增强。
- 每个声源使用互补分量形成目标频谱，连续调整两个频段，沿用包含交叉项的能量归一化。中低频实部响应下限保护扩展到两种独立频段强度，保留原先的身体感保护。
- 3 ms／80 ms 包络判断突发起音与快速衰减尾音，快速撤回、缓慢恢复新增增强；只减小新增部分，不对原始声源设置噪声门，不删除对象或尾音。此处不是语义识别，也不宣称可以识别鼓或人声。
- 原有实测余量补偿保留，共用输出预算。耳机偏好 EQ 后的实际混合信号也进入预算与峰值测量，不从限幅衰减或用户音量滑杆中虚构余量。

## 移动与方向

频段控制按采样平滑，沿用对象成员权重与 HRTF 连续移动链路。个人的后方／上下偏好由归一化方向连续插值得到，交界处采用凸权重，不把后方和高度两次叠加。包括 360RA 下方方向；位置、ITD、HRTF 凹口与耳间电平不被个人偏好重写。头部姿态不参与掩蔽参考，避免转头驱动整曲增益变化。

## 耳机与个人试听

移动端设置增加四步原生系统弹窗：后方辨识、上下辨识、耳机低频、耳机高频。用正在播放的熟悉片段试听，支持逐项重选、与进入前设置比较、保存、取消恢复、恢复默认。iOS 和 Android 共用流程；平板使用相同入口。Expo Go 仅预览流程，明确提示没有原生试听输出。

桌面端空间设置提供同一组参数、比较与恢复。后方／上下参数范围 0.5–1.5，只影响新增细节；低／高架滤波范围 ±3 dB，两耳相同，80 ms 交叉淡化。移动端简化选择为 −2／0／+2 dB。连续修改会合并到最新目标，不重置已播放的淡化。

这是用户听感偏好，**不是测量个人 HRTF、耳道或耳机频响**，也不代表复刻任何实体音箱。默认方向参数为 1，耳机 EQ 为 0 dB。设置通过原生队列应用并分别持久化，重新打开曲目恢复；seek 保留偏好并重置滤波历史。文件调优播放拒绝偏好覆盖；系统空间输出旁路 SDA 处理。

## 延迟与存储

不增加音频延迟线、整曲扫描、歌曲缓存或 JS PCM 传输。自动分析只有固定大小滤波与能量状态；持久化只有四个数值。真实耳机听感和设备界面仍需要安装包试听与目视验收，不能用代码测试代替。
