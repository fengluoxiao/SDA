# 房间电平与原始资料核查

核查日期：2026-09-09。当前档案：`SADIE KU100 Reference / 7.1.4 / 6x4.5x3 m / treated`，ID `3a13f276cb17cd6577362603384bc0a5c8a94d06980e85938b83b019ee1057b4`。

## 原始资料

1. [York SADIE II 官方数据库](https://www.york.ac.uk/sadie-project/database.html)：HRIR 用 Genelec 8010 在头部中心半径 1.2 m 处测量；BRIR 则使用 Genelec 8030/8040，半径 1.5 m。二者不能混用。
2. [SADIE II 原论文，§3.2.3，页 8–10](https://doi.org/10.3390/app8112029)：所有发布的 HRTF 做了扩散场均衡；第一阶段补偿测量系统响应，第二阶段补偿加窗引入的误差。IR 经时间对齐和裁剪，48/44.1 kHz 版本长 256 taps。论文没有为 SDA 的数字输入建立绝对 SPL 标定。
3. [论文官方 PDF](https://mdpi-res.com/d_attachment/applsci/applsci-08-02029/article_deploy/applsci-08-02029.pdf)：已下载并核对上述章节。
4. [pyroomacoustics 官方 ISM 实现](https://github.com/LCAV/pyroomacoustics/blob/master/pyroomacoustics/simulation/ism.py)：`time = dist / c`，`oct_band_amplitude = att / dist`；随后叠加空气吸收和源/接收端指向响应。本机生成器安装版本具有同样公式。

原始 D1.zip 内的 SOFA 文件独立证实：SourcePosition 半径 1.2 m；Data.Delay 为 0；Comment/History 明确记载低频扩展、扩散场均衡和加窗。因此不能把这些 HRIR 称为未经处理的声压实测，也不能仅据测量半径自动乘 1.2 补偿。

## SDA 当前链路

`scripts/room-simulator.py` 从 D1 的 48 kHz / 24 bit WAV 读取 HRIR，用作 MeasuredDirectivity 接收端。当前内置档案的声源为 `ideal-omnidirectional`，不是 Genelec 8020 的实测声源。生成器利用 pyroomacoustics 鞋盒房间、镜像源、空气吸收和墙面吸收生成完整双耳响应。

| 当前虚拟扬声器 | 到听者距离 | `1/r` 对幅度的贡献（以 r=1 m 为数值基准） |
| --- | --- | --- |
| 前左/前右 | 2.2228 m | −6.938 dB |
| 中置 | 1.9250 m | −5.689 dB |
| 侧环绕 | 1.4216 m | −3.056 dB |
| 后环绕 | 2.1780 m | −6.761 dB |
| 顶部四声道 | 1.5344 m | −3.719 dB |

这些值只说明传播项，不能直接当作整首歌最终响度差；反射相干叠加、频率响应和各轨内容都会影响结果。自由场幅度的相对距离规律为 `20 log10(r1/r2)`，距离加倍约 −6.02 dB，是物理传播，不是主音量调节。

档案记录的粉红噪声参考能量：direct −7.6502 dB，full room −4.6800 dB，raw reference −3.1696 dB，calibrated reference −1.7553 dB。raw/calibrated 在生成器中包含 0.04 的原有 wet 混合，并非纯 HRIR 直达响应。故之前约 4.48 dB 的差值只能作诊断线索，不能用作自动补偿。

## 已证实的问题与未证实的部分

- 之前应用房间额外赋予 early −6 dB、late −9 dB，没有本次查到的实测依据；已取消，默认全为 0 dB。
- 不新增按听感、响应能量或 HRIR 测量半径计算的自动增益。
- 房间尺寸、摆位比例 0.7 和 `treated` 吸声数组 `[.25,.40,.60,.70,.72,.72,.70]` 是程序中的设计假设，没有对应具体混音室或实际墙体测试报告。当前档案不得称为某个真实录音棚的实测 BRIR。
- 原先将发布 HRIR 描述为必然完整保留测量扬声器响应/传播延时的说法不严谨；应以论文的测量系统补偿和时间对齐说明为准。
- 现有资料可解释房间开启后变小的一部分，但不能证明整个生成链路已完成绝对声压标定，也不能仅凭音量下降判定仿真正确。

后续若要代表指定录音棚，优先使用有测量位置、声源电平、麦克风校准说明的实测 BRIR；仿真则需明确参考源电平及材料系数来源。真实传播损失保留，未知标定不靠事后整体增益掩盖。

## 本次实现结果（revision 4）

上文数值描述 revision 3 旧档案，保留作为审计记录。新生成器及五种内置布局已改为明确的文献材料系数，详见 builtin-reference-rooms.md 和 scripts/room-materials.json；尺寸与全表面材料覆盖仍为设计假设。

数字参考约定明确为 1 米、1/r 传播、HRIR 按发布数据保留，无测量半径补偿、无自动响度补偿、无绝对 SPL 声称。库默认的整段零相位 10 Hz 高通被关闭，改用同参数因果去直流处理，保留文献要求的镜像源直流伪影修正而不让未来反射影响直达声。输出附加 8192 个采样容纳滤波衰减。

六项物理测试通过：声源朝向、声路距离/时延、距离加倍半幅度、反射不改直达前段、文献材料一致性和反射分段。没有将另一间 SADIE 测量房间的 BRIR 当作本设计房间的真值。


## 新档案人声频段复核

对 revision 4 的 7.1.4 档案 e3563bf4a8acf4a7ea0ac8dac7e05f2a7906e3c8eeca377827432867fc6a6637 做离线响应分析（200–4000 Hz，粉红频率加权，非实际歌曲主观响度）：中置直达相对校准 HRTF 约 -6.10 dB，完整房间约 -4.80 dB；反射/直达能量约 -5.08 dB，完整响应比直达高 1.30 dB。前左/右完整响应相对各自校准 HRTF 约 -5.29/-5.31 dB。相关立体声中心测试完整/直达约 +1.40 dB。

## 录音棚控制室实现（revision 5）

五种布局统一改成 6×5×3.2 m 的偏干近场控制室，所有非 LFE 音箱距听音位 1.2 m，左右对称。前墙和天花为 70% 织物覆面岩棉板，侧后墙为 85% 50 mm / 80 kg/m³ 岩棉，未覆盖部分为双层石膏板；地面为地毯。吸声系数仍来自所引用的文献数据库，覆盖率、尺寸、监听距离属于设计选择。

参考 [EBU Tech 3276](https://tech.ebu.ch/docs/tech/tech3276.pdf) 的早反射筛查条件，以及 [Genelec 摆位说明](https://www.genelec.com/monitor-placement) 的左右对称和边界反射原则。1.2 m 并非上述资料规定的唯一正确距离。本方案立体声基线小于 EBU 的 2–4 m，250–4000 Hz 的 Eyring 估算约 0.09–0.16 s，低于 EBU 的参考范围；125 Hz 估算约 0.44 s。它是偏干近场设计，不宣称 EBU 合规或某个真实录音棚的复刻。Eyring 不是测量值，尤其不能当作低频驻波预测。

最终 7.1.4 响应离线复核（200–4000 Hz、粉红加权）：中置反射/直达约 −5.69 dB，前左/右约 −7.40/−7.33 dB；完整响应相对各自校准 HRTF 约 −0.92/−0.30/−0.27 dB。中置直达变化来自 1.925 m 改为 1.2 m 的真实模型距离变化，而非输出增益。直达、早反射、晚反射默认均为 0 dB，不做自动归一化。相关立体声中心完整/直达约 +1.21 dB。这些是响应能量指标，不能替代歌曲主观试听。

所有布局分别保存六面吸声系数、距离、声路、Eyring 估算和一阶反射筛查结果；UI 展示每面材料覆盖与近场距离。有效均匀表面模型不模拟单块吸声板位置、桌面、扩散体或低频波动。理想全向声源也不等同于真实录音棚音箱的指向性。
